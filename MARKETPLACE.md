<h2>Discover Your Developer DNA</h2>

<p><strong>Your Git history has a personality. Discover yours.</strong></p>

<p>Dev Wrapped is a free, open-source JetBrains IDE plugin that transforms local Git activity into a polished, shareable Developer DNA card. Choose a Git identity and reporting period, then discover a playful archetype based on patterns in your own commit history.</p>

<h3>Features</h3>

<ul>
  <li>Six deterministic archetypes, including The Midnight Architect, The Commit Machine, and The Bug Whisperer.</li>
  <li>Commit activity, active days, streaks, peak times, fix signals, and file-based language activity.</li>
  <li>Last 30 days, This year, and All time reporting periods.</li>
  <li>A high-resolution 1200 × 1500 share card.</li>
  <li>Full-resolution PNG export and image clipboard copying.</li>
</ul>

<h3>Privacy First</h3>

<p>All Git analysis and image rendering happen locally. Dev Wrapped uses no accounts, backend, telemetry, or AI APIs. It does not upload source code, commit messages, identities, repository names, paths, or remote URLs. Share cards contain anonymous aggregate statistics only, and nothing is shared automatically.</p>

<h3>How It Works</h3>

<ol>
  <li>Open a Git-backed project.</li>
  <li>Choose <strong>Tools → Dev Wrapped → Generate My Dev Wrapped</strong>.</li>
  <li>Select a Git identity and reporting period.</li>
  <li>Generate the card, then choose <strong>Save PNG…</strong> or <strong>Copy Image</strong>.</li>
</ol>

<h3>Disclaimer</h3>

<p>Git activity is not a measure of time spent, productivity, skill, or impact. Developer DNA archetypes are deterministic, playful interpretations of commit patterns—not scientific assessments.</p>
