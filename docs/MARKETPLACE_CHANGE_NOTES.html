Dev Wrapped 0.1.4

The first stable release of Dev Wrapped.

  • Generate a private Developer DNA card from local Git activity.
  • Choose an exact Git identity and analyze Last 30 days, This year, or All time.
  • Discover one of six deterministic developer archetypes.
  • Export a full-resolution 1200 × 1500 PNG or copy the rendered image directly.
  • Uses verified public IntelliJ Platform APIs for supported IDE versions.

All Git analysis and rendering happen locally, with no accounts, telemetry, uploads, or AI APIs.
